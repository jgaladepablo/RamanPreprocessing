This is a GUI developed by Julia Gala de Pablo to allow people new to the world of Raman spectroscopy to explore Raman pre-processing and multivariate training. 
The GUI uses MATLAB built-in functions and other published functions (specifically for background subtraction) referenced below. See the tutorial word file to guide you through the process for the provided example data.

References

Martens H., Stark E. Extended multiplicative signal correction and spectral interference subtraction: New preprocessing methods for near infrared spectroscopy. Journal of Pharmaceutical and Biomedical Analysis, 9(8), 625-635 (1991). 
Skogholt J., Liland K.H., Indahl U.G. Pre-processing of spectral data in the extended multiplicative signal correction framework using multiple reference spectra. Journal of Raman Spectroscopy, 50(3), 407-417 (2019).
