This is a GUI developed by Julia Gala de Pablo to allow people new to the world of Raman spectroscopy to explore Raman pre-processing and multivariate training. 

The GUI uses MATLAB built-in functions and other published functions referenced below. Specifically, the function for baseline subtraction was first developed by Martens et al 1991 and adapted for Raman spectra by Koch et al 2016. The background subtraction approach was written by the author adapting the algorithm described by Skogholt et al 2019. 

See the tutorial Word file to guide you through the process for the provided example data.

References

Martens H., Stark E. Extended multiplicative signal correction and spectral interference subtraction: New preprocessing methods for near infrared spectroscopy. Journal of Pharmaceutical and Biomedical Analysis, 9(8), 625-635 (1991).

Koch, Matthias & Suhr, Christian & Roth, Bernhard & Wollweber (née Meinhardt), Merve. (2016). Iterative morphological and mollifier‐based baseline correction for Raman spectra. Journal of Raman Spectroscopy. 48. 336-342. 10.1002/jrs.5010. 

Skogholt J., Liland K.H., Indahl U.G. Pre-processing of spectral data in the extended multiplicative signal correction framework using multiple reference spectra. Journal of Raman Spectroscopy, 50(3), 407-417 (2019).
